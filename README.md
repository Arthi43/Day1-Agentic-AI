# Day 1 - Agentic AI

## Comparing a Plain Chatbot, Rule-Based Workflow, and AI Agent

## Scenario

Student Assignment Tracker

The private data contains assignment names, subjects, due dates, and completion status.

Example user request:

"What are my pending assignments?"

## Approaches

### 1. Plain Chatbot

The plain chatbot mainly uses an LLM to provide a response to the user's request.

### 2. Rule-Based Workflow

The rule-based workflow follows predefined steps and conditions to process the assignment data.

### 3. AI Agent

The AI agent combines LLM + Tools + Loop to reason about the task, use tools, observe results, and continue actions until the task is completed.

## Project Structure

- Output - Contains screenshots of all three systems
- chatbot - Plain chatbot code
- workflow - Rule-based workflow code
- agent - AI agent code
- analysis.md - Detailed written analysis
- student_data.json - Private assignment data
